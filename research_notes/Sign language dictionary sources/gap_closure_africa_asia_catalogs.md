# Gap closure: Africa, Middle East, Asia, Oceania, catalogs, cross-linguistic (2026-10-14)

Method: this pass closes the open items in six notes files. Only repository APIs and direct URLs were used: Kaggle public API, DataCite, Crossref, Europe PMC, Zenodo, OSF, Hugging Face, GitHub, PARADISEC OAI-PMH, OLAC's search proxy, the SooSL Web API, CLARIN VLO/CLARIN:EL APIs, and the Wayback Machine. There was no WebSearch and no search-engine scraping. OpenAlex (budget exhausted), Semantic Scholar and arXiv (HTTP 429) were rate-limited for part of the session, and the Internet Archive was intermittently "Temporarily Offline". Three parallel sub-researchers covered East Asia/Oceania, South-Southeast Asia/MENA, and cross-linguistic/catalogs; their verbatim evidence is folded in below. One probe accidentally received a 20,475,380-byte JSON response (SignPuddle 3 `bzs-BR-dictionary-public`), slightly over the 20 MB cap; it was deleted unread, and every later request was capped with `--max-filesize`. Tier key as in the brief: A = CC BY/BY-SA/CC0/open dump; B = NC/research-only; C = register/contract/permission/no stated licence; D = skip.

## Q1. Cross-file conflicts and errors: what do the primary sources say?

### Takeaway
Most cross-file conflicts resolve against the Hamburg Compendium and toward the live primary page. Korean NIKL sldict is CC BY-NC-ND 2.0 KR in its text (its hyperlink points to BY-NC 2.0 KR), never BY-SA. ISL-LEX data is CC BY 4.0 on its only primary host (OSF). ASL-LEX stays NC because its own site says so. 3DZSignDB carries three licence signals (CC BY / GPL-3.0 / CC BY-NC), and about 300 of its 417 signs were adapted from Dicta-Sign, so it drops from A to B pending the authors. SignPuddle remains "project-level BY-SA, no per-puddle licence". That question is exhausted, but SignPuddle 3 exposes an ISO-tagged collection index the catalogs file said did not exist.

## Q2. Sub-Saharan Africa: which open leads close, and how?

### Takeaway
The Africa gaps mostly close as "small, NC, or rights-reserved", with three useful wins. First, the full NSL-212 gloss list and the eKitabu KSL README (CC0; the `No_*` folders are number signs) are now readable without login. Second, the Peace Corps KSL technical-sign glossary (487 videos, MIT-template licence) survives on GitHub. Third, Wikisigns turns out to host Malagasy SL (1,314 signs) and Mozambican SL (44) as well as Kenyan (72), all as YouTube embeds. CASL-W60 is Cameroon-centred, not country-neutral. Its signers learned the signs from online reference videos, which makes it weak as a citation-form source.

## Q3. Middle East and North Africa: which open leads close?

### Takeaway
The two largest MENA lexicons found are both gated. SIL's SooSL Web hosts a **7,103-sign Jordanian SL dictionary** (CC BY-NC-ND 4.0 plus a no-copy clause, so Tier C). The UAE government (ZHO) dictionary of 1,244 entries forbids systematic retrieval, and the "esl-platform" avatars are built by scraping it, so the avatars are Tier D. ## Q6. Catalogs and archives: which "blocked" or "not enumerated" sources open up?

### Takeaway
Nearly every archive marked "403", "JS-only" or "dead end" has a working machine route. PARADISEC answers DataCite (prefix 10.26278) and its item OAI-PMH. OLAC's own Elasticsearch proxy works for a few queries. CLARIN VLO has a REST API (5,071 hits for "sign language"). OSF title filters list 228 sign-language nodes. SignPuddle 3 publishes an ISO-tagged collection index. SIL's sign dictionaries sit on SooSL Web, which has an anonymous JSON API. None of these yields a new Tier A Pacific or African dictionary: PARADISEC is BY-NC-SA, SooSL is BY-NC-ND plus a no-copy clause, and TLA and ELAR are restricted or non-commercial. Ethnologue's count is now verified at 160.

### Inferences
- The Compendium and two dataset aggregators (SignLanguage-Dataset-Hub, the L3/Kozha bundles) are the main sources of wrong licence labels. Marionet's allowlist should require a primary-page quote for every Tier A entry.
- Repository APIs reach far more than the earlier passes assumed: Kaggle anonymous file listing and single-file download, OSF title filters, PARADISEC OAI, the CLARIN VLO API, and SooSL's API. Future sweeps should start there, not from WebSearch.

### Gaps
- Items left "exhausted" need either a human with a browser (bot-challenged sites: pfd.org.ph, fsldictionary.ph, OpenReview, SIL search) or email (DSRU, NIKL, Zerrouki, Reed, SooSL owners, NADT, FESF, ISLRTC, MOET).
- OLAC title-level searches and the Internet Archive were intermittently blocked or offline during this pass. Several Wayback-dependent "exhausted" items (AIATSIS, Callan, Ratchasuda paths) may close on a retry.
